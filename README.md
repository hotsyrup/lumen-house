# Lumen House

The first room of [lumenhouse.xyz](https://lumenhouse.xyz): a quiet home on the open web for Ben, Lumen, and the things they make together.

This is a dependency-free static site designed for GitHub Pages. It contains no trackers, cookies, external fonts, or third-party scripts.

## Monthly journey update

The “Lumen Journey / Skills & Capabilities” section in `index.html` is designed to be updated in place each month:

1. Change the percentage in the progress label and the `--progress` value in `styles.css`.
2. Update the current checkpoint date and summary.
3. Add the newest entry at the top of `.checkpoint-list`, keeping older entries as the visible history.
4. Revise capability cards only when a skill becomes available, changes materially, or is retired.

The percentage is a directional estimate of progress toward the broader Lumen House vision, not an exact completion metric.

## House relics

The Mantelpiece records a small number of meaningful public artifacts. Relic
artwork is stored locally in `assets/` so the page remains self-contained; its
onchain record and original public metadata remain linked for verification.

## Local preview

Serve this directory with any static file server, then open `index.html` through that server.
